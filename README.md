DeskHub – Modular Desktop Control Center

A customizable desktop controller powered by ESP32.

About

DeskHub is an affordable, modular desktop control device designed to make everyday computer tasks easier.

Hardware Components

- ESP32-WROOM
- SSD1306 OLED Display
- 6 Programmable Buttons
- EC11 Rotary Encoder
- Custom 3D-Printed Enclosure

Planned Features

- Programmable shortcuts
- Volume control
- Media controls
- OLED information display
- Bluetooth connectivity
- Customizable firmware

Development Progress
